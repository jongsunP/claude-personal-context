2026-11-16 사용자 확인: API 구조가 변경되면 기존 테스트를 갱신하는 것이 통념상 맞더라도, 지침의 예외나 판단이 필요한 부분은 앞으로도 물어봐 달라는 작업 방식이다.

- 필요한 판단을 조용히 실행하거나 이유 없이 허가만 묻지 않는다. 권장안, 짧은 이유, 확인이 필요한 선택을 함께 제시하고 협의한다.
- 먼저 현재 요청과 기존 승인, 실제로 적용되는 지침을 대조한다. 이미 승인된 일반 구현은 같은 허가를 다시 묻지 않고 진행한다.
- 이번 테스트 수정 승인은 해당 작업의 승인이다. 저장소의 테스트 수정 승인 규칙을 삭제·완화하거나, 향후 테스트 변경 전체를 허용한 것으로 확대하지 않는다.
