name: 제품 간 동일 동작과 저장 중 UI 검증
description: 한 제품의 문제를 고치면 같은 요구사항의 다른 제품도 동작과 코드 처리 기준을 맞추고 검증
type: feedback
---

2026-11-13 사용자 확인: 치과앱에서 알림 설정 저장 문제를 수정한 뒤 기공소앱에 같은 시각적 문제가 남았다. 단순히 제보된 버그만 고치는 것이 아니라, 제품별로 달라야 할 정책/기술적 이유가 없는 동일 동작은 구현 방식과 완료 기준을 맞추는 것이 기본이다.

- 다른 구현에서 같은 스피너가 없다는 이유만으로 문제없음으로 처리하지 않는다. 저장 전/중/후 글자·스위치 색상, opacity, 스피너, 레이아웃·스크롤 위치와 중복입력 차단·실패 복구를 함께 확인한다.
- 일시적인 저장 중 입력 차단과 실제 권한/오류의 비활성 외형은 구분한다. 공용 컴포넌트를 불필요하게 바꾸거나 모든 제품을 같은 코드로 추상화하라는 뜻은 아니다.
- 동일 흐름의 웹·치과앱·기공소앱을 제한된 관련 범위에서 대조하고, 바뀐 앱의 최종 코드를 iOS/Android에서 확인한다. 변경 없는 검증 증거는 재사용한다.
- 확인하지 못했다면 해당 제품/OS/조건을 명시하고 꼭 필요한 실기기 확인만 사용자에게 요청한다. 미확인을 완료로 묶지 않는다.
