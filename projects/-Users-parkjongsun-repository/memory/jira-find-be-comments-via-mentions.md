BE가 FE에 주는 API·스펙 안내는 보통 상위 카드 댓글에 달린다. 그런데 BE 본인 카드에 다는 경우도 있다(예: 알림 설정 구조 변경 안내가 DL-16140이 아닌 DL-17114 댓글 44978). 상위 카드에서 못 찾으면, 사용자(Frankie)를 멘션한 댓글, 즉 사용자의 지라 알림에 뜨는 댓글을 기준으로 하위 카드들을 찾아본다.

**Why:** 사용자는 지라 알림으로 이런 안내를 받는다. 상위 카드만 보고 "없다"고 판단하면 실제 근거를 놓친다.

**How to apply:** 상위 카드 댓글 확인 → 없으면 같은 상위의 BE 하위 카드 댓글 중 사용자 멘션이 있는 최신 댓글을 확인한다. 노션 등 BE 문서 링크는 사용자가 따로 줄 수 있다.
