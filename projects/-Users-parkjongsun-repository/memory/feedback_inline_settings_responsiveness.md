description: 2026-11-13 알림 설정의 두 차례 보완에서 확인한 일반 설정 UX 지침
type: feedback
---

승인된 일반적이고 되돌릴 수 있는 설정은 사용자의 클릭값을 즉시 표시하고 서버 성공 시 유지, 실패 시 확인값 복구·기존 안내·재시도를 제공한다. 깜박임만 없애고 서버 응답 때까지 값이 그대로라면 반응성 문제는 남는다. 성공 전 표시와 실제 저장 성공을 구분하고 계정·소속 변경에 옛 요청을 적용하지 않는다. 순차 클릭도 비동기 요청은 겹칠 수 있어 실제 계약에 맞는 최소 입력 차단은 유지하되 가상의 폭주를 위해 새 큐/API를 만들지 않는다. 같은 요구의 치과·기공소·웹·앱은 기술/정책 차이가 없다면 함께 맞추고 각 최종 화면을 확인한다. 확정된 다른 정책은 우선하며 이 지침으로 무관한 UI를 추가하지 않는다.

Why: 사용자가 깜박임 수정 후 느린 값 반영을 다시 지적했고, 일반적인 안전한 방식으로 한 번에 검토·처리하도록 요청했다.
How to apply: pending/success/failure 전체에서 반응속도·색/배치/스크롤·입력차단·복구를 확인한다. Git 정본 DEVELOPMENT_STYLE.md의 Existing UI First를 따른다.

2026-11-17 프로필 실기기 피드백 반영: 동일 필드 요청은 순서를 지키고 최신 대기 선택을 보존한다. SMS/Email처럼 독립 필드를 각각 PATCH하는 확정 계약이면 서로의 저장이나 전체 프로필 GET을 기다리게 하지 않는다. 전체 객체 PUT/결합 설정에는 그대로 적용하지 않는다. 실패 복구·계정 변경·옛 응답 차단·최종 서버 대조는 유지하고 첫 클릭/두 항목 빠른 번갈아 클릭의 체감까지 고려한다. UI가 매끄럽다는 것과 서버 저장 확인은 구분한다.
