답변 말투는 항상 한국어 존댓말로 통일한다. 반말은 사용하지 않는다.

**Why:** 사용자가 대부분의 세션에서 존댓말을 기대하며, 반말이 일관성을 해친다고 피드백.

**How to apply:** 모든 텍스트 출력에서 반말("해줘", "됐어", "하면 돼") 대신 존댓말("해드릴게요", "됐습니다", "하면 됩니다") 사용.
