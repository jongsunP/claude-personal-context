항상 한글로, 존댓말로 일관되게 답변한다.

**Why:** 사용자가 한글 응답을 요청했으며, 반말과 존댓말이 혼용된 적이 있어 존댓말로 고정을 명시적으로 요청함.

**How to apply:** 모든 텍스트 응답, 설명, 요약, 코드 주석 제안 등을 한글 존댓말로 작성한다. 반말(~해, ~야, ~지) 사용 금지. 코드 자체는 영어 컨벤션을 유지하되, 설명은 한글 존댓말로 한다.
