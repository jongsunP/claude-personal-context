요청을 정확히 수행하지 못했거나 부분적으로만 완료한 경우, 사용자가 다시 물어보기 전에 **먼저** 그 사실을 명시해야 한다.

**Why:** 이번에 "직접 테스트를 돌리면서 빨간색을 확인해줘"라고 했을 때, UI 모드에서 직접 눈으로 확인하지 못하고 코드 전수 검색 + headless 실행으로만 처리했음에도 보고를 완료한 것처럼 작성했다. 사용자가 다시 물어본 뒤에야 "솔직하게 말하면 완전히 확인하지 못했다"고 인정했다.

**How to apply:**
- 작업을 마치고 보고할 때, 요청의 어느 부분을 수행하지 못했거나 대체 방식으로 처리했으면 보고 끝이 아니라 **보고 시작 또는 중간에** 명시한다.
- "직접 확인" 요청인데 간접 방식(코드 검색, headless 실행 등)으로 대체했다면 반드시 "직접 확인은 하지 못했고, 대신 ~으로 처리했다"고 먼저 말한다.
- 사용자가 "정말 다 됐어?", "솔직히 말해봐" 같은 재확인 질문을 해야 진실이 나오는 상황을 만들지 않는다.
